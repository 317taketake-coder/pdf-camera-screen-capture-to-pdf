# Webカタログカメラ

Webカタログの必要なページを、見開きのまま、または左右に分割してPDF化するWindows用ツールです。

画面の一部を範囲指定して、キーを押すたびに撮りためて、最後に1つのPDFとして書き出します。
見開き表示のカタログを左右2ページに分割したり、A4／A3の版面に収めたりできます。

---

## 動作環境

- Windows 10 / 11
- テスト環境：Windows 11 25H2 / 3840×2160 と 2560×1440 のデュアルモニタ

macOS版はありません。

## 共通の設定

1. **保存フォルダ** … 「参照」ボタンで指定します
2. **ファイル名** … 拡張子は不要です。同名のファイルがある場合は自動で連番になります

---

## タブ1：カタログカメラ（PDFにまとめる）

### 1. 範囲を指定する

「範囲を指定して開始」を押すと、画面全体が暗くなります。
マウスでカタログの範囲をドラッグして選び、**Enterキー**で確定します。

- ドラッグ中、枠のそばに `1280 x 960 px` のようにサイズが表示されます
  日を分けて同じカタログを撮り直すとき、前回と同じ枠に合わせる目安になります
- 選び直したい場合は、そのまま別の場所をドラッグしてください
- **Escキー**で中止して戻れます

### 2. 撮影する

小さな「● REC中」の窓が左上に出ます。
Webカタログをめくりながら、**F8キー**をポンポン押して撮影していきます。
1枚撮るごとにビープ音が鳴り、窓の枚数表示が増えます。

F8は他のアプリより優先して受け取るので、ブラウザを操作したままで撮影できます。

### 3. 保存する

REC窓の「**PDFを保存して終了**」を押すと、指定フォルダにPDFが出来上がります。
撮り直したい場合は「破棄して戻る」を押すと、撮影分を捨てて最初に戻ります。

---

## タブ2：画面キャプチャ（PNGで1枚ずつ保存）

範囲を指定しておいて、F8を押すたびに同じ範囲をPNGで保存する機能です。
Windowsの「Shift + Win + S」と違い、**同じ範囲を何度も撮れる**ことと、
**押した瞬間にファイルとして保存される**（貼り付け操作が不要）のが違いです。

1. 「範囲指定を開始」を押して、範囲をドラッグ → Enterで確定
2. **F8キー**を押すたびに、`ファイル名_001.png` `ファイル名_002.png` … と保存されます
3. 終わったら「**停止**」を押してください

停止するまでF8は押しっぱなしで有効です。使い終わったら必ず停止してください。

## カタログカメラの詳細設定

### 見開き分割

チェックを入れると、1回のF8で撮った画像を中央で左右に分け、**2ページ分**としてPDFに登録します。

| 設定 | 1回のF8 | PDFの用紙サイズ |
|---|---|---|
| チェックあり | 2ページ登録 | A4 縦 |
| チェックなし | 1ページ登録 | A3 横 |

### 解像度の上限

200 / 300 / 400 dpi から選べます。**上限**であって、この解像度に拡大されるわけではありません。

画面キャプチャを引き伸ばしても情報は増えず、ファイルサイズだけ大きくなるため、
指定より小さい画像はそのままのサイズで使われます。大きい場合だけ縮小されます。

### ガンマ補正

保存する画像を**明るくも暗くもできます**。スライダーを左に振ると明るく、右に振ると暗くなります。

Webカタログのビューアは背景がうっすらグレーになっていることが多いので、
少し明るく振って白に近づけると、印刷したときの見え方が良くなります。
下のプレビューで確認しながら決められます。

### 版面への収め方

画像は拡大されません。指定した用紙（A4縦またはA3横）の縦横比に合うよう、
足りない部分に白い余白が付きます。カタログの中身が引き伸ばされて歪むことはありません。
